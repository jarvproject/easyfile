## 🚀 О проекте

**EasyFile** — это легковесный, быстрый и эффективный инструмент для работы с файловой системой в среде **Linux**, написанный на чистом **C**. Проект создан для тех, кто ценит скорость, минималистичность и производительность низкоуровневого кода без лишних зависимостей.

> ⚠️ **Статус версии 0.10:** Проект находится на стадии активной разработки. Текущий релиз включает в себя базовый стабильный функционал управления файлами.

---

## ✨ Ключевые возможности

* **Высокая скорость:** Минимальное потребление ресурсов благодаря компиляции в чистый машинный код.
* **Никаких зависимостей:** Используются только стандартные системные вызовы Linux и POSIX библиотеки.
* **Безопасность памяти:** Весь код тщательно оптимизирован для предотвращения утечек памяти (memory leaks).

## 🛠 Требования и установка

### Зависимости
Для сборки проекта вам понадобятся стандартные инструменты разработки Linux:
* Компилятор `gcc`

### Сборка из исходников

Выполните следующие команды в вашем терминале:

```bash
# Клонируйте репозиторий
git clone https://github.com/jarvproject/easyfile.git

# Перейдите в директорию проекта
cd EasyFile

# Скомпилируйте проект
./setup.sh
```

---

## 💻 Использование

Запустите скомпилированный бинарный файл:

```bash
/usr/bin/easyfile [опции] <путь_к_файлу>
# Или
easyfile [опции] <путь_к_файлу>
```

*Для вывода полного списка доступных флагов используйте команду:*
```bash
./easyfile --help
```
